# 을지포차 POS 디자인 시스템 (DESIGN.md)

QR 테이블오더 서비스의 점주용 POS 화면 디자인 시스템. 사용자(고객) 화면과 동일한 테마를 기반으로, Figma 없이 코드 레벨 디자인 토큰 + 컴포넌트 스펙으로 정의한다.

---

## 1. 개요

- **대상 기기**: iPad 11인치 (1194 × 834pt, landscape 기준) / 반응형 대응
- **기준 방향**: 가로(landscape) — 매장 카운터에 거치하는 POS 용도이므로 가로 레이아웃을 1순위로 설계하고, 세로/축소 화면에서는 컬럼이 세로로 재배치됨
- **테마 연속성**: 고객용 주문 화면(밝은 오렌지 포인트 컬러, 화이트 카드, 라운드 코너, 미니멀 플랫 스타일)을 그대로 계승
- **핵심 화면 구성**: ① 테이블 현황 그리드 ② 현장 주문 대기 리스트 ③ 포장 주문 대기 리스트 ④ 관리자(매출) 탭

---

## 2. 디자인 토큰

### 2.1 컬러

고객 화면 캡처 기준으로 추출한 값. 실제 Figma 컬러칩이 있다면 수치는 그대로 대체.

```css
:root {
  /* Primary — 브랜드 오렌지 */
  --color-primary: #FF6B2C;         /* 강조 버튼, 사용중 테이블, 스테퍼 */
  --color-primary-dark: #F0561A;    /* 눌림/활성 상태 */
  --color-primary-light: #FFE4D1;   /* 연한 배경 칩 (예: "주문내역" 배지) */
  --color-primary-tint: #FFF3EB;    /* 카드 내 아주 옅은 하이라이트 */

  /* Surface / Background */
  --color-bg: #F5F5F7;              /* 전체 배경 */
  --color-surface: #FFFFFF;         /* 카드, 패널 배경 */
  --color-surface-muted: #EDEDEF;   /* 비활성 탭, 빈 테이블 배경 */

  /* Text */
  --color-text-primary: #1A1A1A;
  --color-text-secondary: #8C8C8F;  /* 설명/보조 텍스트 */
  --color-text-inverse: #FFFFFF;    /* 오렌지 배경 위 텍스트 */

  /* 상태 컬러 (테이블/주문 상태 구분용) */
  --color-state-empty: #D9D9DC;      /* 빈 테이블 (어둡게/무채색) */
  --color-state-occupied: #FF6B2C;   /* 사용중 테이블 (밝게/오렌지) */
  --color-state-occupied-bg: #FFF3EB;/* 사용중 테이블 카드 배경 */
  --color-state-new-order: #FF3B30;  /* 신규 주문 알림 배지 (레드) */
  --color-state-warning: #FFB020;    /* 대기시간 임계 초과 경고 */

  /* Border / Shadow */
  --color-border: #ECECEE;
  --shadow-card: 0 4px 16px rgba(0, 0, 0, 0.06);
  --shadow-floating: 0 6px 20px rgba(255, 107, 44, 0.35); /* 오렌지 CTA용 */
}
```

### 2.2 타이포그래피

고객 화면과 동일한 라운드 산세리프 계열(Pretendard 등) 사용. 숫자(가격, 매출)는 굵게 강조.

| 토큰 | 크기 / 굵기 | 용도 |
|---|---|---|
| `--font-display` | 28px / Bold | 총 매출 등 핵심 숫자 |
| `--font-title` | 20px / Bold | 테이블 번호, 카드 제목, 섹션 헤더 |
| `--font-body` | 16px / Medium | 메뉴명, 주문 항목 |
| `--font-caption` | 13px / Regular | 보조 설명, 타임스탬프 |
| `--font-badge` | 12px / Bold | 배지/칩 텍스트 |

### 2.3 스페이싱 & 라운드

```css
:root {
  --radius-card: 20px;      /* 카드 코너 */
  --radius-pill: 999px;     /* 버튼, 스테퍼, 탭 */
  --radius-chip: 12px;      /* 작은 배지 */

  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 32px;
}
```

터치 타겟 최소 크기: **44 × 44pt** (버튼, 스테퍼, 배지 탭 영역 포함).

## 3. 전체 레이아웃 구조

가로(landscape) 기준 3구역 분할. 화면은 **상단 헤더 + 하단 2컬럼(메인/사이드바)** 구조.

```
┌─────────────────────────────────────────────────────────────┐
│  헤더: 로고 | 매장명 | 오늘 매출 요약 | [테이블] [관리자] 탭   │
├───────────────────────────────────┬───────────────────────────┤
│                                   │  🟠 현장 주문 대기 (N)     │
│         테이블 현황 그리드          │  ┌───────────────────┐   │
│    (사용중 / 빈 테이블 카드들)      │  │ 대기 주문 카드      │   │
│                                   │  └───────────────────┘   │
│   [1] [2] [3] [4]                │  ...                     │
│   [5] [6] [7] [8]                ├───────────────────────────┤
│   ...                            │  📦 포장 주문 대기 (N)     │
│                                   │  ┌───────────────────┐   │
│                                   │  │ 대기 주문 카드      │   │
│                                   │  └───────────────────┘   │
└───────────────────────────────────┴───────────────────────────┘
```

- **메인 영역 (약 68%)**: 테이블 그리드. 매장 좌석 배치 수에 맞춰 카드 개수 자동 생성
- **사이드바 (약 32%)**: 상/하로 "현장 주문 대기" · "포장 주문 대기" 2개 섹션을 고정 분할. 각 섹션은 독립 스크롤
- 사이드바는 실시간 배지 카운트(N)로 대기 건수 표시, 새 주문 도착 시 카드가 리스트 최상단에 삽입 + 짧은 하이라이트 애니메이션

## 4. 컴포넌트 스펙

### 4.1 테이블 카드 (Table Card)

정사각형에 가까운 비율(1:1 ~ 4:3), 그리드로 배치.

| 상태 | 배경 | 테두리/강조 | 표시 내용 |
|---|---|---|---|
| 빈 테이블 | `--color-state-empty` (무채색, 어둡게) | 없음 | 테이블 번호만 중앙에 크게 |
| 사용중 (주문 있음) | `--color-state-occupied-bg` (밝은 오렌지 톤) | 좌측 상단 오렌지 바 또는 카드 외곽선 `--color-primary` | 테이블 번호 + 주문 미리보기(대표 메뉴명 + "외 N건") + 경과 시간 + 합계 금액 |
| 대기시간 초과 (예: 60분+) | 동일 + `--color-state-warning` 배지 | 배지 깜빡임 없이 색만 강조 | 경과시간 배지 강조 |

카드 내부 레이아웃(사용중 상태):
```
┌──────────────────────┐
│ 3번 테이블      12:04 │  ← 테이블 번호 + 주문 경과시간
│                      │
│ 소세지 야채볶음 외 2건 │  ← 주문 미리보기 (최대 2줄)
│                      │
│           8,500원    │  ← 합계 금액
└──────────────────────┘
```

- 탭(터치) 시 **주문 상세 모달** 오픈: 전체 주문 항목, 수량, 금액, 주문 시각
- 상세 모달 하단에 **[테이블 정리]** 버튼(destructive 스타일, outline + red 텍스트) → 확인 다이얼로그("테이블을 정리하시겠습니까?") → 확인 시 주문 데이터 초기화, 카드가 빈 테이블 상태로 즉시 복귀
- 빈 테이블 카드는 탭해도 반응 없음(또는 "수동 주문 등록" 액션 예약)

### 4.2 대기 주문 카드 (현장 / 포장 공통)

리스트형 카드, 사이드바 폭에 맞춰 세로로 쌓임.

```
┌───────────────────────────────┐
│ 🟠 3번 테이블 (현장)   3분 전  │
│ 소세지 야채볶음 x1             │
│ 물 x2                         │
│─────────────────────────────  │
│ 합계 8,500원     [주문 접수]   │
└───────────────────────────────┘
```

- 포장 주문 카드는 테이블 번호 대신 **주문번호 + 픽업 예정시각** 표시, 아이콘은 📦
- 액션 버튼: `[주문 접수]` → `[준비중]` → `[완료]` 단계형 상태 전이(원컬러 버튼, 상태별 라벨/컬러만 변경)
- 경과 시간이 길어질수록 캡션 컬러를 `--color-text-secondary` → `--color-state-warning`으로 전환

### 4.3 헤더

- 좌측: 로고(고객 화면과 동일 워드마크) + 매장명
- 중앙/우측: 오늘 매출 요약 미니 위젯(선택), 새로고침 아이콘
- 우측 끝: 세그먼트 탭 `[테이블 현황] [관리자]` — 고객 화면의 "메뉴/기타" 탭과 동일한 필(pill) 스타일 재사용 (활성 = 연한 회색 필 배경, 비활성 = 텍스트만)

### 4.4 관리자 탭 (매출 확인)

- **총 매출** 카드: 오늘 매출 합계를 `--font-display` 크기로 최상단에 크게 표시
- 하위 요약: 현장 주문 매출 / 포장 주문 매출 분리 표시, 총 주문 건수, 평균 객단가
- 기간 필터: 오늘 / 이번 주 / 직접 선택 (세그먼트 탭 또는 드롭다운)
- 하단: 매출 추이 또는 주문 내역 테이블(선택 사항, 1차 스코프 아님)
- 스타일: 다른 화면과 동일하게 화이트 카드 + `--shadow-card`, 숫자만 오렌지 포인트로 강조 가능

### 4.5 공통 버튼

| 종류 | 스타일 |
|---|---|
| Primary (주문 접수, 완료 등) | 배경 `--color-primary`, 텍스트 화이트, `--radius-pill` |
| Secondary (필터, 보조 액션) | 배경 `--color-surface-muted`, 텍스트 `--color-text-primary` |
| Destructive (테이블 정리) | 배경 화이트, 테두리+텍스트 red(#FF3B30) |
| 스테퍼(+/-) | 고객 화면과 동일한 오렌지 필 스타일 유지 (수량 조정이 POS에도 필요할 경우) |

## 5. 반응형 규칙

| 브레이크포인트 | 대상 | 레이아웃 변화 |
|---|---|---|
| ≥ 1024px (iPad 11" landscape 기준) | 기본 | 메인/사이드바 2컬럼, 테이블 그리드 4~5열 |
| 768px – 1023px (iPad portrait / 축소창) | 축소 | 테이블 그리드 3열, 사이드바 폭 축소(고정 최소폭 280px) |
| < 768px | 소형/비상용 | 사이드바가 하단 탭(현장/포장 전환)으로 전환, 테이블 그리드 2열, 전체 세로 스택 |

- 테이블 그리드는 항상 `auto-fill` 방식으로 카드 최소폭(약 140px) 기준 자동 열 계산 → 테이블 수가 매장마다 달라도 대응
- 사이드바 두 섹션(현장/포장)은 화면이 좁아지면 상단 세그먼트 탭으로 전환하여 하나씩 노출

## 6. 상태 요약 (한눈에 보기)

| 요소 | 비활성/기본 | 활성/강조 | 경고 |
|---|---|---|---|
| 테이블 | 무채색 배경, 번호만 | 오렌지 톤 배경 + 주문 미리보기 | 대기시간 초과 시 배지 컬러 변경 |
| 주문 대기 카드 | 화이트 카드 | 신규 도착 시 좌측 오렌지 바 + 잠깐 하이라이트 | 장시간 미처리 시 캡션 red 톤 |
| 탭 (테이블/관리자) | 텍스트만 | 연회색 필 배경 | - |

## 7. 다음 단계

이 문서는 1차 초안이며, 실제 기기 테스트 후 다음 항목을 조정 예정:
- 정확한 컬러 HEX 값 (Figma 원본 대조)
- 테이블 그리드 열 수 / 카드 최소 크기
- 관리자 탭 매출 상세 항목 범위
- 실시간 신규 주문 알림 방식(사운드/애니메이션 포함 여부)
